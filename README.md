# demo_exam_test

*всё приложение в папке project*

Для крутых пошаговый `terminal`

Шаг 1. Проверка Python

```
python --version
```

если нет установите *https://www.python.org/downloads/*

Шаг 2. Открыть терминал в папке проекта

```
cd C:\Users\User\Desktop\demo_exam_test\project
```

Шаг 3. Установка Flask

```
pip install flask
```
или для Linux РОСА
```
python3 -m venv .venv
source .venv/bin/activate
pip install Flask
```
**Шаг 4. Запуск приложения**
```
python app.py
```
*Внимание: Просматривать проект следует только через запущенное приложение. Просмотр HTML-файла не даёт полной картины.*
```
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:8080
Press CTRL+C to quit
```
*http://127.0.0.1:8080 -> тык на запущенное приложение.*
